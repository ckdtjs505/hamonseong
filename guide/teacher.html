관리자 대시보드 및 학생 관리 방법을 안내합니다

v2.0 · 2026년 9월 업데이트

✦ 관리자 주요 기능

교사/리더 권한으로 사용할 수 있는 관리 기능들입니다.

📊 대시보드 홈 전체 현황 한눈에
👥 사용자 관리 학생 정보 & 권한
📋 반별 진행사항 O/X 진행 체크
🏆 열정 랭킹 학생 완독 순위
📝 함온성 기록 관리 기도문 조회 & 삭제
📅 함온성 계획 관리 읽기 계획 설정

📋 목차

  1. 어드민 페이지 접속
  2. 대시보드 홈 — 전체 현황 확인
  3. 사용자 관리
  4. 반별 진행사항 관리
  5. 열정 랭킹
  6. 함온성 기록 관리
  7. 함온성 계획 관리

1 어드민 페이지 접속

선생님(리더/어드민) 권한을 가진 계정으로 로그인해야 관리자 기능에 접근할 수 있습니다.

  1. 메인 페이지에서 로그인합니다.
  2. 화면 우측 상단에 나타나는 어드민 노란색 버튼을 클릭합니다.
  3. 관리자 대시보드로 이동합니다.
⚠️
어드민 버튼이 보이지 않는다면 관리자 권한이 부여되지 않은 상태입니다. 총괄 관리자에게 권한 부여를 요청해주세요.
🔐
권한 종류:
  • student — 일반 학생 (관리 기능 접근 불가)
  • leader — 리더/선생님 (자기 반 관리 가능)
  • admin — 총괄 관리자 (전체 관리 가능)

2 대시보드 홈 — 전체 현황 확인

대시보드 홈에서는 전체 학생들의 성경 읽기 현황을 한눈에 파악할 수 있습니다.

📈 통계 요약 카드

페이지 상단에 주요 통계가 카드 형태로 표시됩니다.

  • 전체 사용자 수
  • 오늘 완독한 학생 수
  • 전체 함온성 기록 수

📊 반별 진행 현황 테이블

각 반(Class)별로 다음 정보를 확인할 수 있습니다:

  • 소속 인원 — 해당 반에 배정된 학생 수
  • 오늘의 진행률 — 오늘 함온성을 완료한 비율
  • 전체 진행률 (누적) — 전체 읽기 계획 대비 누적 달성률
  • 남은 목표 수 — 아직 완료하지 못한 읽기 일수

🕐 최근 제출 기록

가장 최근에 함온성을 제출한 학생 5명의 이름, 반, 일차, 제출 날짜가 표시됩니다.

3 사용자 관리

학생들의 정보를 조회하고, 반 배정 및 권한을 변경할 수 있습니다.

  • 좌측 메뉴에서 사용자 관리를 클릭합니다.
  • 전체 사용자 목록이 테이블로 표시됩니다.

📝 관리할 수 있는 항목

  • 이름 — 학생의 실명
  • 반(Class) — 소속 반 (미지정, 1반, 2반 등)
  • 아이디(Username) — 로그인 아이디
  • 권한 — student / leader / admin
  • 관리 버튼 — 반 배정, 권한 변경, 계정 삭제 등
⚠️
학생 계정을 삭제하면 해당 학생의 모든 기록이 영구 삭제됩니다. 신중하게 진행해주세요.

4 반별 진행사항 관리

읽기 계획 전체 일정을 기준으로 학생별 O/X 진행 현황을 한눈에 확인할 수 있습니다.

  • 좌측 메뉴에서 반별 진행사항 관리를 클릭합니다.
  • 상단 반별 필터 버튼으로 특정 반만 모아볼 수 있습니다 (전체, 미지정, 1반, 2반 등).
  • 이름 검색 입력창으로 특정 학생을 빠르게 찾을 수 있습니다.

📋 진행사항 테이블 읽는 법

  • 열(Column) = 읽기 계획의 각 일차(Day)
  • 행(Row) = 각 학생
  • O = 해당 일차 함온성 완료
  • X = 미완료
💡
가로 스크롤하여 전체 일정의 진행 상황을 확인하세요. 특히 연속 X가 많은 학생에게 격려가 필요할 수 있습니다.

5 열정 랭킹

전체 학생의 완독 순위를 확인할 수 있습니다.

  • 좌측 메뉴에서 열정 랭킹을 클릭합니다.
  • 완독 횟수가 많은 학생 순으로 랭킹이 표시됩니다.

📊 테이블 항목

  • 순위 — 완독 횟수 기준 순위
  • 이름 — 학생 이름
  • 반(Class) — 소속 반
  • 완독 횟수 — 함온성 완료 총 횟수
  • 최근 활동일 — 마지막으로 함온성을 완료한 날짜

6 함온성 기록 관리

학생들이 작성한 모든 함온성(묵상/기도) 기록을 조회하고 관리할 수 있습니다.

  • 좌측 메뉴에서 함온성 기록 관리를 클릭합니다.
  • 전체 기록이 최신순으로 표시됩니다.

📝 확인할 수 있는 항목

  • 날짜 — 읽기 계획 날짜
  • 작성자 — 학생 이름
  • 회차 — 읽기 계획 Day 번호
  • 선택구절/기도 — 학생이 선택한 구절과 작성한 기도문
  • 작성일시 — 실제 제출 시각
  • 관리 — 기록 삭제 기능
⚠️
부적절한 내용이 포함된 기록은 삭제할 수 있습니다. 삭제된 기록은 복구할 수 없으므로 주의해주세요.

7 함온성 계획 관리

성경 읽기 계획(어떤 날짜에 어떤 본문을 읽을지)을 설정하고 관리합니다.

  • 좌측 메뉴에서 함온성 계획 관리를 클릭합니다.
  • 현재 등록된 읽기 계획 목록을 확인할 수 있습니다.
  • 날짜별로 읽기 범위(성경 본문)를 지정하거나 수정할 수 있습니다.
📌
읽기 계획은 학생들이 매일 읽을 성경 본문의 기준이 됩니다. 계획을 변경하면 학생 화면에 즉시 반영됩니다.
🛠️

시스템 오류가 발생하거나 추가 기능 건의가 있다면
관리자에게 문의해 주세요.
